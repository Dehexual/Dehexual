## `01` — The Idea

Dehaxual is my space for turning ideas into working software.

This account is separate from my main learning-focused profile. Here, I experiment with personal apps, small utilities, automation, and AI-assisted development.

Not every project needs to become a startup. Sometimes, building something useful is the whole point.

|---|---|---|

| **Future Experiments** | Small apps, automation tools, and ideas worth testing. | Ongoing |

*Project statuses will change as development progresses.*

## `03` — Development Philosophy

- **Build over hype.** Focus on working software, not flashy announcements.
- **AI is a tool.** Use AI to accelerate development while reviewing, testing, and understanding the code.
- **Keep it practical.** Solve a real problem, even if the solution is small.
- **Experiment freely.** Not every idea will work, and that's part of development.
- **Improve continuously.** Fix bugs, simplify code, and learn from mistakes.

## `05` — Project Standards

Every project should aim to include:

- A clear README and setup instructions.
- A description of its features and limitations.
- Sensible error handling and basic testing.
- No committed passwords, API keys, or private credentials.
- Honest documentation of AI assistance where relevant.
